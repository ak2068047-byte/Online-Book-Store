# Online Book Store SQL Project

This SQL project analyzes an online book store database to gain useful business insights from customers, books, orders, and sales data.

## Project Objective
The main goal of this project is to practice SQL queries and perform data analysis on an online bookstore database.

## Tools Used
- MySQL
- SQL Workbench

## SQL Concepts Used
- SELECT Statements
- WHERE Clause
- ORDER BY
- GROUP BY
- Aggregate Functions
- JOINS
- Subqueries

## Project Analysis
This project answers important business questions such as:
- Best-selling books
- Top customers
- Total revenue generated
- Most popular book categories
- Customer purchase analysis
- Order statistics

## Database Tables
- Books
- Customers
- Orders
- Order Details

## Features
- Sales Analysis
- Customer Insights
- Revenue Tracking
- Book Category Analysis
- SQL Query Practice

## Conclusion
This project helped improve SQL skills and understand how SQL is used for real-world business data analysis.
